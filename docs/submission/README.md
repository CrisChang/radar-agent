# Radar Agent final submission pack

This directory contains the final field copy and supporting notes for the
Encode Club x Circle Programmable Money Hackathon submission.

Public links:

- Live demo: <https://radar-agent-arc-2026.chrischang2026.chatgpt.site>
- Demo video: <https://radar-agent-arc-2026.chrischang2026.chatgpt.site/demo>
- Source: <https://github.com/CrisChang/radar-agent>
- Deck: <https://github.com/CrisChang/radar-agent/blob/main/docs/deck.pdf>
- Arc receipt: <https://testnet.arcscan.app/tx/0xb552e86788532a48013355c5165e68bd50b56a24e0dd6ec2a5d28b005e687726>

The public experience is intentionally safe: it validates the live x402
payment requirement and replays an immutable proof record, but it cannot sign
or broadcast arbitrary transfers.
